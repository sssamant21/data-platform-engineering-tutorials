## Decisions and confirmed corrections

The original **20/20 priority entries** have now received a contextual human-readable disposition. **Two Chapter 70 lessons had misleading copyable command syntax**, and **one Chapter 25 failure example** omitted a required argument while illustrating a dangerous approach. Those were corrected/qualified. **The Chapter 02 pod connectivity diagnostic** next to a conceptual comparison had an actionable plaintext `redis-cli` example; it has been replaced with a scoped **authenticated, CA-verified TLS** diagnostic. Other examples are intentional conceptual representations or templates; changing them into runnable code could be less safe and pedagogically incorrect.

- **Chapter 02:** Approved pod-context Redis `PING` example requires `REDIS_HOST`, `REDIS_PORT`, readable `REDIS_CA` and ephemeral `REDISCLI_AUTH` via an approved secret mechanism. Uses `redis-cli --tls --cacert`; accommodates an ACL user, documents optional client certificate/key for mTLS, does not suppress TLS failures, and records *NOT EXECUTED* in V02.
- **Chapter 25:** `INCR counter; EXPIRE counter` is explicitly **unsafe schematic pseudocode** rather than two independently copyable Redis operations. `EXPIRE` requires a duration; a crash between `INCR` and `EXPIRE` can leave a persistent rate-limit state.
- **Chapter 70, Lab 3:** Replaced `HGET one field` / `HGETALL` with correctly formed **HSET/EXPIRE/HGET/HGETALL** over an exact disposable hash, expected values and exact-key `UNLINK`. Large-object experiments require separately approved bounds.
- **Chapter 70, Lab 5:** `MGET 10` reads one key named `10`; it does **not** request ten keys. Replaced misleading shorthand with a three-key, same-hash-tag (cluster-friendly), expiring **SET/MGET** smoke and safe UNLINK cleanup. Any 10/100/1000-key trials require separately approved key lists, size limits, metric capture and SLO gates.

Official syntax and transport sources: [MGET](https://redis.io/docs/latest/commands/mget/), [HGET](https://redis.io/docs/latest/commands/hget/), [Redis Software TLS](https://redis.io/docs/latest/operate/rs/security/encryption/tls/enable-tls/).

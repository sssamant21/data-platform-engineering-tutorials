### Gate B — Static command and manifest validation

- Extract fenced YAML, JSON, Bash, PowerShell and Kafka CLI snippets, classifying complete runnable examples versus intentional templates/placeholders.

- Run `kubectl apply --dry-run=client` only for applicable, complete Kubernetes objects; verify CRD schema against the installed Strimzi version in an isolated cluster.
- Check `apiVersion`, RBAC, resource requests, Pod security, NetworkPolicy, Secret handling, PVC topology and pinned image references.
- Compare Kafka CLI flags, Kafka API support, Strimzi CRDs and managed service capabilities against tested versions.
- Never automatically execute destructive commands extracted from documentation.

**Pass condition:** all runnable examples parse; templates are clearly labeled; no critical unsafe or invalid command examples.
